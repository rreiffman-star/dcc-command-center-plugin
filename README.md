# Command Center plugin

Public install surface for Ross Reiffman's private `rreiffman-star/dcc-command-center`
repository. It carries only the plugin manifests and skill instructions, generated by
`scripts/mirror_plugin.py` from release 0.12.0. Operating rules, logs, tests, scripts,
and sender lists stay private; the skills fetch them at a verified commit at runtime, so
the plugin does nothing useful without access to the private repository through the
GitHub connector plus the Todoist and mail connectors.

Claude Cowork: Customize > Plugins > Browse plugins > Add marketplace, enter
`rreiffman-star/dcc-command-center-plugin`, then install Command Center.

Claude Code:

```
/plugin marketplace add rreiffman-star/dcc-command-center-plugin
/plugin install command-center@dcc-command-center
```

Do not edit this repository directly; regenerate it from the private release.
